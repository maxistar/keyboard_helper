Flappy Key-Bird

Type each gate target in rhythm to flap through the opening.

How to play

  1. Type the visible target; every correct symbol gives one flap.
  2. Finish the target before its gate passes the bird.
  3. Wrong keys count as mistakes and give no lift.
  4. Avoid the pipes, floor, and ceiling.
  5. Press Esc whenever you want to pause.
