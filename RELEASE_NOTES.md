# Release Notes

## v0.6.0

- Added the first Keyboard Helper Companion preview for API 31+ `arm64-v8a` Android phones.
- Added independent Browse layout viewing plus stock ZMK connection status and available standard
  Battery/Device Information evidence.
- Added read-only Live layer, key, combo, and bounded diagnostic telemetry for compatible enhanced
  Keyboard Helper firmware; the mobile companion follows physical layers and never controls them.
- Added bounded BLE recovery, foreground lifecycle handling, accessible small-screen presentation,
  signed APK verification, SHA-256 checksums, and preview-to-preview update support.
- The Android preview is foreground-only and distributed as a GitHub release APK, not through
  Google Play. iOS remains planned but unavailable.

## v0.2.0
- Added external files support for loading layouts/configs without rebuilding.
- Unified the JSON layout format so all layouts share the same structure.
- Created a uniform pop-out menu for consistent layout options across the app.
