## Default Permission

Foreground read-only Keyboard Helper BLE transport proof

#### This default permission set includes the following:

- `allow-permission-status`
- `allow-request-permissions`
- `allow-start-scan`
- `allow-stop-scan`
- `allow-connect`
- `allow-list-services`
- `allow-read`
- `allow-subscribe`
- `allow-unsubscribe`
- `allow-disconnect`
