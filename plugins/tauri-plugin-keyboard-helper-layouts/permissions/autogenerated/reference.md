## Default Permission

Purpose-bounded custom layout import and private storage

#### This default permission set includes the following:

- `allow-pick-layout`
- `allow-list-records`
- `allow-write-record`
- `allow-remove-record`
- `allow-read-selection`
- `allow-write-selection`
