# Website Screenshots

The homepage uses these stable filenames for product screenshots. If an image is temporarily absent, the page renders a styled placeholder instead of a broken image element.

- `overlay-main.png` - main overlay with live key highlighting.
- `menu-keyboard.png` - application menu with the Keyboard flyout open.
- `menu-language.png` - Language flyout with macOS input-source synchronization status.
- `settings-window.png` - Settings window showing layout and hotkey configuration.
- `mini-mode.png` - compact Mini Mode overlay with restore control.
- `self-test.png` - Keyboard Self-test controller with overlay outline state.
- `typing-invaders.png` - Shift-Space Invaders during active play.

Android workspace slots use these names and are shown only when the linked release metadata enables `adaptiveWorkspace`:

- `android-browse.png` - phone-width Browse workspace with the keyboard stage visible; alt text: "Android Companion Browse workspace showing a selected keyboard layout."
- `android-settings.png` - adaptive Settings with Connection, Layouts, and Status destinations; alt text: "Android Companion adaptive Settings with connection, layout, and status sections."
- `android-live.png` - enhanced-firmware read-only Live presentation; alt text: "Android Companion Live view following read-only keyboard layer and key telemetry."

If one of these files is absent, the homepage renders an accessible placeholder containing the subject and expected path. Development captures must not be added or enabled as current-release screenshots until the corresponding APK has been published and accepted.
