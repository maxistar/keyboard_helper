# Website Screenshots

The homepage uses these stable filenames for product screenshots. If an image is temporarily absent, the page renders a styled placeholder instead of a broken image element.

- `overlay-main.png` - main overlay with live key highlighting.
- `menu-keyboard.png` - application menu with the Keyboard flyout open.
- `menu-language.png` - Language flyout with macOS input-source synchronization status.
- `settings-window.png` - Settings window showing layout and hotkey configuration.
- `mini-mode.png` - compact Mini Mode overlay with restore control.
- `self-test.png` - Keyboard Self-test controller with overlay outline state.
- `typing-invaders.png` - Shift-Space Invaders during active play.
